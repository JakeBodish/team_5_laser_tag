### HOW TO RUN ###

Sprint3:  
1. Run install.sh
2. Run main.py 
3. On player entry screen input player ID and hit TAB 
4. If it is a new player, you will be prompted to enter a new codename 
5. Enter the equipment ID for the player, hit TAB 
6. Press F2 to configure server IP
