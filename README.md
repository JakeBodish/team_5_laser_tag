### HOW TO RUN ###

Sprint3:
1. in terminal: sed -i 's/\r$//' install.sh
2. bash install.sh
3. python3 main.py
4. On player entry screen input player ID and hit TAB 
5. If it is a new player, you will be prompted to enter a new codename 
6. Enter the equipment ID for the player 
7. Press F2 to configure server IP 
8. Press COMMA to enter action screen and begin game start countdown
9. Press F12 to clear entries from player entry screen
